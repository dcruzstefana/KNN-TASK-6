# KNN-TASK-6
KNN TASK 6
This project demonstrates the implementation of the K-Nearest Neighbors (KNN) classification algorithm using the popular Iris dataset. The goal is to classify iris flowers into one of three species based on their sepal and petal dimensions. The dataset is first preprocessed by removing unnecessary columns and standardizing the feature values to ensure fair distance calculations. The KNN model is then trained and evaluated using various values of K to identify the optimal number of neighbors for classification. The model's performance is assessed through accuracy scores and visualized using a confusion matrix. To further enhance understanding, dimensionality reduction is performed using Principal Component Analysis (PCA) for plotting decision boundaries, which visually demonstrate how the KNN algorithm separates different species in a 2D space. Additionally, a pair plot is included to explore feature relationships and species distribution.
